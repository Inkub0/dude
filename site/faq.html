FAQ

Common questions, short answers.

The basics

Is DUDE free? Do I still need to buy the game?

DUDE is free and open source. It is only the engine, the program that runs the game, so you need your own copy of DOOM 3 and/or Quake 4 for the maps, sounds and textures.

Which versions of DOOM 3 work?

The original 2004 DOOM 3 and Resurrection of Evil, patched to 1.3.1: the Steam and GOG versions (already patched) or the CD/DVD (apply the 1.3.1 patch). DOOM 3: BFG Edition and the Bethesda.net Edition don't work, because they store the game in a different format; but buying DOOM 3 on Steam or GOG includes the original version too. See how to recognise the right folder.

Does it change the game? Will my original game still work?

The gameplay is unchanged, and the lowest preset (Potato) is the original rendering. DUDE only adds files to your game folder; Doom3.exe / Quake4.exe keep working exactly as before.

Is there a macOS version?

Not at the moment: DUDE is built for 64-bit Windows and Linux (including SteamOS).

Can I play multiplayer?

DUDE focuses on single player. Quake 4 multiplayer is not supported yet. For DOOM 3, the old network code is not considered safe on the internet: play only on a LAN with people you trust.

Hardware and graphics

What PC do I need?

A 64-bit Windows 10/11 or Linux PC (or a Steam Deck) and a graphics card with OpenGL 3.3 covers the classic and OpenGL 3 renderers: practically any card from the last fifteen years.

The Vulkan renderer needs a graphics driver that supports Vulkan 1.4. Most cards from recent years get it with an up-to-date driver; older cards may stop at Vulkan 1.3 or below, and then the OpenGL 3 renderer is the one to use.

Ray tracing needs ray-tracing hardware: NVIDIA GeForce RTX (20 series and newer), AMD Radeon RX 6000 and newer, or Intel Arc. Path Tracing is demanding; it is meant for upper mid-range and high-end cards, ideally with FSR 2 upscaling on.

Which renderer and preset should I choose?

Try Vulkan with the High preset first. If Vulkan doesn't start or you see problems, use OpenGL 3. On older or low-power hardware, Medium or Low. Want the 2004 experience? Potato.

The Vulkan renderer won't start.

Update or reinstall your graphics driver: the Vulkan support comes with it. On Windows, download the driver from NVIDIA, AMD or Intel directly rather than relying on Windows Update. The OpenGL renderers are not affected, so you can keep playing with OpenGL 3 meanwhile.

My frame rate dropped a lot.

Lower the preset one step, or turn Ray Tracing down from Path Tracing to On or Off. On Vulkan, FSR 2 upscaling (in the F10 settings menu) renders fewer pixels and scales the image up, which gives a large boost at high resolutions. On laptops, make sure the game runs on the dedicated graphics card and the charger is plugged in.

Ray Tracing doesn't appear in the menu.

It shows only with the Vulkan renderer on a card with ray-tracing hardware. Switch the renderer to Vulkan first, and update your driver.

Using DUDE

Where are my settings and savegames?

In DUDE's own folder, separate from the game: Documents\My Games\dude on Windows, ~/.local/share/dude on Linux and SteamOS. Back up that folder to keep your saves.

Can I continue my old savegames?

Yes. DUDE loads saves from the retail DOOM 3, from dhewm3 and from every earlier DUDE release. Copy your old save files into DUDE's savegames folder (inside the folder above, under base for DOOM 3).

Does my controller work?

Yes, any controller your system recognises. A new install starts without pad bindings: open the settings menu (F10 or DUDE Settings in the main menu) > Bindings > Reset Gamepad Bindings to Xbox-style Defaults.

Do mods work?

Mods made for dhewm3 1.5.5 work, including many with their own game code and shaders. Install a mod into its own folder next to base as its instructions say, then pick it from the Mods menu.

How do I start Resurrection of Evil or The Lost Mission?

From the Mods entry in DUDE's main menu. The Lost Mission needs the community port installed first: see the install guide.

What are the "baked shading packs"? Do I need them?

Optional files that add soft shading to the creases of characters, weapons and props. Nice to have, not needed. Details on the downloads page.

Windows says "Windows protected your PC".

DUDE is not signed with a paid certificate, so SmartScreen warns about it. Click More info > Run anyway, but only for files from this site or the official GitHub releases.

How do I uninstall it?

Delete the files DUDE added to the game folder; the list is in the install guide. Delete DUDE's settings folder too if you don't want to keep your saves.

Still stuck?

Open an issue on GitHub or leave a comment on ModDB. Say which game, which version of DUDE, Windows or Linux, and your graphics card. If the game started, the log file dudelog.txt in DUDE's settings folder helps a lot.
