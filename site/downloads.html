Which files do I need?

Just one, most of the time: DUDE for your system. Everything else is for Quake 4 players or is an optional extra.

I want to play...Download
DOOM 3, Resurrection of Evil or The Lost MissionDUDE for Windows or DUDE for Linux / SteamOS
Quake 4DUDE for your system + the Quake 4 add-on for your system
...and I'd like extra shading detailAdd the matching baked shading pack (optional)

"Windows" means 64-bit Windows 10 or 11. "Linux" means any 64-bit x86 Linux, including SteamOS on the Steam Deck. There is no macOS version at the moment.

Quake 4 add-on

Only needed for Quake 4. It contains Quake 4's game code (how weapons, monsters and the story behave), which comes from Raven Software's Quake 4 SDK. That code has its own licence, separate from DUDE's: free, non-commercial use only. So it is a separate download, with the licence file inside. It contains no Quake 4 game data: you still need your own Quake 4.

Optional: baked shading packs

These packs add ambient occlusion: the soft darkening where surfaces meet, in the folds of a monster's skin, the creases of a weapon, the gaps of machinery. Without it, characters and props can look a little flat and "pasted on". The shading is computed in advance ("baked") once for every model of the game, so it costs almost nothing while you play.

  • Not required. DUDE runs fine without them; they are large, so they are a separate download.
  • Used by the Low to Nightmare presets on OpenGL 3 and Vulkan. Not used by Potato (the original look) or by the Path Tracing setting, which computes this shading live.
  • Download once: a pack is not tied to a DUDE version. It only changes when the baking itself improves, and keeps working when you update DUDE.
  • You can switch it off any time: F10 > Baked Occlusion Maps.

How to install a pack

No unzipping: the .pk4 file is used as it is. Just put it in the right folder inside your game folder.

  • DOOM 3 pack: into the base folder (next to pak000.pk4). It also serves Resurrection of Evil and The Lost Mission.
  • Quake 4 pack: into the q4base folder.

Both files have the same name, so keep them apart: don't save one over the other in your Downloads folder. Upgrading from DUDE 0.9.7 or older? Delete the old z_baked_ao_*.pk4 files (props, weapons, roe, lm) from your game folders; this single pack replaces them.
