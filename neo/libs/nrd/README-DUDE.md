# Vendored NVIDIA NRD (Real-Time Denoisers) — DUDE notes

NRD v4.18, vendored from https://github.com/NVIDIA-RTX/NRD at commit
`6227e737e9c1f7ef1733cb59acb241f6f316778e` (MIT, see LICENSE.txt) for the RTX hybrid
roadmap's H2 denoiser framework (docs/rtx-hybrid-roadmap.md, docs/rtx-nrd.md). Mirrors the
FSR2 vendoring pattern (libs/fsr2): sources + PREBUILT embedded SPIR-V headers, so the
engine build needs no HLSL toolchain (no DXC/ShaderMake at build time).

What is vendored (and from where):

- `Include/`, `Source/`, `Resources/` — the NRD library as-is.
- `Shaders/*.cs.spirv.h` — the 31 compute shaders PRECOMPILED to SPIR-V byte arrays,
  generated by NRD's own build (ShaderMake + DXC v1.9, `--headerBlob`, Vulkan 1.2,
  register shifts s0 b2 u3 t20); plus the upstream `Shaders/*.hlsli` headers, which the
  C++ side also includes (resource/constant layout macros — `InstanceImpl.h` pulls
  `../Shaders/NRD.hlsli`). SPIR-V was compiled with the upstream default config:
  `NRD_NORMAL_ENCODING=2` (R10G10B10A2_UNORM octahedral world normals),
  `NRD_ROUGHNESS_ENCODING=1` (linear), all `NRD_SUPPORTS_*` ON except VIEWPORT_OFFSET,
  `REBLUR_PERFORMANCE_MODE` OFF. The C++ build flags in neo/CMakeLists.txt MUST match
  these (they do — see the `nrd` target), or InstanceDesc lies to the integration.
- `MathLib/` — NRD's MathLib dependency (header-only; its own LICENSE.txt inside).
- `ShaderMake/ShaderBlob.{h,cpp}` — the tiny blob-format parser the runtime uses to read
  the embedded `--headerBlob` arrays (from the ShaderMake repo, pinned by NRD's build).

To regenerate (e.g. on an NRD version bump):

```
git clone --depth 1 --recursive https://github.com/NVIDIA-RTX/NRD.git
cd NRD && cmake -B _Build -DNRD_NRI=OFF -DNRD_STATIC_LIBRARY=ON && cmake --build _Build -j
# ShaderMake downloads DXC by itself; then re-copy:
#   Include/ Source/ Resources/ LICENSE.txt        -> libs/nrd/
#   _Shaders/*.spirv.h + Shaders/*.hlsli           -> libs/nrd/Shaders/
#   _Build/_deps/mathlib-src/{ml.h,ml.hlsli,Guts,LICENSE.txt} -> libs/nrd/MathLib/
#   _Build/_deps/shadermake-src/ShaderMake/ShaderBlob.{h,cpp} -> libs/nrd/ShaderMake/
```

Local changes vs upstream: none (pristine copy).
